# TeamCraft guide

TeamCraft is a self-hosted, end-to-end encrypted business team chat with calls and meetings. This
guide describes what the code on `main` does today. Features that are designed but not built are
marked *coming soon*.

| Guide                                 | For                           |
|---------------------------------------|-------------------------------|
| [User guide](user/index.md)           | People who use TeamCraft      |
| [Administrator guide](admin/index.md) | People who install and run it |

Design documents (the *why*): [ARCHITECTURE.md](../../ARCHITECTURE.md), [PLAN.md](../../PLAN.md) and
[docs/](../). For developers: [README.md](../../README.md) and [AGENTS.md](../../AGENTS.md).
