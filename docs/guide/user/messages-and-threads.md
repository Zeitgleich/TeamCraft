# Messages and threads

## Write a message

Type in the composer and press **Enter** (or **Ctrl/Cmd+Enter**, a setting under Settings >
Display). Messages support a safe Markdown subset: `**bold**`, `_italic_`, `` `code` ``, code blocks,
lists, quotes and links. No HTML is rendered.

- **@name** mentions a person; mentions notify at the *Mentions* level.
- **Urgent** messages: the server repeats the push in DMs every two minutes (default, up to five
  times) until the recipient acknowledges. They never break through do-not-disturb or a mute. The
  composer has no urgent toggle yet (coming soon).
- Messages from the same author close together are grouped.

## Reactions

Hover a message and choose the reaction button (👍); choose an existing reaction chip to add or remove yours. An emoji picker is coming soon.

## Threads

Reply in a thread to keep a conversation tidy.

1. Open the thread of a message (`Enter` on a focused message, or the reply button). The thread opens in a side panel.
2. You **follow** a thread automatically when you reply, when it is your message, or when you are
   mentioned in it. Follow or unfollow by hand any time.
3. **Threads** (`Alt+T`) is your inbox of followed threads, newest activity first, with unread and
   mention counts.

## Direct message extras

In DMs and group DMs the sender sees **Seen by** after you read a message. Read receipts are
reciprocal: if you turn them off in Settings > Privacy, you neither send nor see them.

## Keyboard

| Keys                  | Action                       |
|-----------------------|------------------------------|
| `Ctrl/Cmd+K`          | Quick switcher               |
| `Ctrl/Cmd+Shift+F`    | Search                       |
| `Alt+Up` / `Alt+Down` | Previous / next conversation |
| `Alt+T`               | Threads                      |
| `Ctrl/Cmd+,`          | Settings                     |
| `Ctrl/Cmd+/`          | All shortcuts                |
| `Esc`                 | Close dialog or side panel   |
